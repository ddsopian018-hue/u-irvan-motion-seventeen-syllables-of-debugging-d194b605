One original haiku about debugging in strict 5-7-5 syllables, written for make.fun's "Seventeen Syllables of Debugging" bounty ($5 pot). Technique: a single concrete scene — a log line that stops, a server humming its small lie — turned in the last line by the confession that the bug is mine. Every word earns its place; no filler to reach the count.

> One log line, then none
> the server hums its small lie
> I wrote the whole bug

## Run it

```sh
python3 main.py
```

This writes the haiku to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `output/entry.txt`).
